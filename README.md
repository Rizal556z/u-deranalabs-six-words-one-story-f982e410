## What it does

`main.py` (Python 3.13, pure stdlib, no network) writes one original
six-word story to `/output/entry.txt` — a wedding ring that fits someone
else, a whole marriage in six words.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The output is UTF-8, 34 Unicode code points, exactly six words, well
within the 1–60 character limit.
